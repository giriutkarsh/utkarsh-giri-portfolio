# Utkarsh Giri — Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Open `projects/bank-loan/index.html` to view the Bank Loan case study.

## Publish with GitHub Pages
1. Open your repository: `https://github.com/giriutkarsh/utkarsh-giri-portfolio`
2. Upload the **contents** of this folder to the repository root (not the enclosing folder).
3. Commit the upload to the `main` branch.
4. Go to Settings → Pages.
5. Under Build and deployment choose `Deploy from a branch`.
6. Select `main` and `/(root)`, then Save.
7. Wait for deployment and use the Visit site link.

Expected URL: https://giriutkarsh.github.io/utkarsh-giri-portfolio/

## Editing
- Main page text and sections: `index.html`
- Main visual design: `styles.css`
- Navigation, cursor and active section behavior: `script.js`
- Bank Loan case study: `projects/bank-loan/index.html`
- Case study styling: `projects/bank-loan/case.css`
- Dashboard screenshots and PDF: `projects/bank-loan/assets/`
- SQL file: `projects/bank-loan/sql/`

## Notes before publishing
- Replace `utkarshgiri@example.com` in `index.html` with your preferred professional email.
- Check that the public resume PDF is the version you want to share.
- The project says dataset source is Topmate.io based on the owner's supplied information. Confirm its redistribution rights before sharing the raw data or public interactive report.
- The Bank Loan case study describes a learning project and does not claim real-world banking outcomes.
- Academic project descriptions are intentionally brief until original materials are compiled.
- Freelance VFX details can be expanded later.
- The Forged Mind Instagram account is intentionally not in the main navigation; it can be added as a discreet footer link if desired.

## Technology
HTML5, CSS3, vanilla JavaScript. No build tools or package installation required.
